从今天起，刺桐说社群的数据能力正式走出社群的对话框——**「刺桐说金融数据」MCP 连接器已成功入驻 WorkBuddy**。会员只需在 WorkBuddy 的「连接器」里安装、填入会员密钥，就能让自己的 AI 助手直接查询 A 股、港股、美股的 K 线、财务、资金流、筹码、龙虎榜、研报等**35 类金融数据**。

不用 WorkBuddy？也没关系。Claude Desktop、Cursor、Trae 等任何支持 MCP 协议的客户端，一行配置就能接上这同一套数据服务。

## 一、先花一分钟搞懂：MCP 是什么？

MCP（Model Context Protocol）可以理解成**"给 AI 装上数据接口的通用插头"**。

过去我们让 AI 帮忙看财报、算指标，无非两种做法：要么自己复制粘贴，要么让 AI 凭记忆"猜"。前者累，后者不可信。

有了 MCP，AI 会在需要的时候**主动调用真实的数据服务**，把"查回来的原始数据"而不是"背下来的印象"作为回答依据。数据准不准、有没有缺失，一眼可查、可核对。

「刺桐说金融数据」就是刺桐说社群为会员提供的那个"MCP 数据接口"。

## 二、WorkBuddy 用户：在「连接器」里一键安装

**前提**：WorkBuddy 版本不低于 4.24.0。

安装只要三步：

1. 打开 WorkBuddy，进入「连接器」；
2. 搜索并选择「刺桐说金融数据」；
3. 点击安装，按提示填入你的**刺桐说会员密钥**，完成。

几点说明：

- 密钥仅保存在本机 `~/.workbuddy` 目录下，**不会上传云端**；
- 服务端会实时校验会员身份，**未开通或已到期的会员无法连接**；
- 会员密钥即你的刺桐说会员编号，获取方式见文末。

安装完成后，你可以直接对 AI 说一句"帮我看看贵州茅台最近 30 个交易日的走势"，它就会自动调用工具取回真实数据，而不需要你做任何额外操作。

## 三、非 WorkBuddy 用户：一行配置接入自定义 MCP 客户端

「刺桐说金融数据」是一个标准的 MCP Streamable HTTP 服务，任何兼容 MCP 的客户端都能接入。把下面这段配置放进客户端对应的 mcp 配置文件即可：

```json
{
  "mcpServers": {
    "citongshuo-data": {
      "type": "streamableHttp",
      "url": "https://data.citongshuo.online/mcp",
      "headers": { "Authorization": "Bearer 你的会员密钥" },
      "timeout": 60000
    }
  }
}
```

- **服务地址**：`https://data.citongshuo.online/mcp`
- **认证方式**：请求头 `Authorization: Bearer <你的会员密钥>`

各客户端的落点：

- **Claude Desktop**：编辑 `claude_desktop_config.json`；
- **Cursor**：编辑 `.cursor/mcp.json`；
- **Trae**：在 MCP 面板添加自定义服务器，选择 Streamable HTTP，填入同样的地址与请求头。

配置完成后重启客户端，你就能在工具列表里看到 35 个以 `citongshuo_data_` 开头的工具。
